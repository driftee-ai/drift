# Installation

Install the `drift` CLI using your preferred package manager.

## Homebrew (macOS & Linux)

```bash
brew tap driftee-ai/drift
brew install drift
```

## Go

If you already have a Go environment set up, you can install the latest release directly:

```bash
go install github.com/driftee-ai/drift@latest
```

## Manual Installation

You can download pre-compiled binaries for your OS directly from the [GitHub Releases page](https://github.com/driftee-ai/drift/releases).
